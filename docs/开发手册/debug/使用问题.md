1.DATABASE_URL_SYNC: unbound variable — dev.sh 从未 source .env，导致所有变量为空。在脚本开头加了 set -a; source .env; set +a。

postgres:5432 无法解析（socket.gaierror）— 后端在本机运行，DATABASE_URL 使用的是 Docker 内部主机名。在启动 uvicorn 时改为注入 DATABASE_URL_LOCAL（localhost:5433）和 REDIS_URL_LOCAL。

端口 5432 冲突 — 另一个项目容器占用了 5432，改为 POSTGRES_PORT=5433 并同步更新了 _LOCAL 系列 URL。

2.种子数据重建成功。正确的命令是：

cd /Users/mac/virtual-town/backend
DATABASE_URL_SYNC="postgresql+psycopg://virtual_town:virtual_town_dev@localhost:5433/virtual_town" \
  .venv/bin/python -m app.db.seed
系统中没有全局 python 命令（macOS 默认不创建），需要：

使用 .venv/bin/python（项目虚拟环境）
通过 DATABASE_URL_SYNC 把数据库地址指向宿主机端口 localhost:5433（Docker 映射的 5432→5433）
