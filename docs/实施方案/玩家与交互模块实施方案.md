# 玩家与交互模块实施方案

> 模块定位：真实用户在虚拟世界中的角色、移动、点击交互、对话和事件触发

---

## 1. 设计目标

玩家不是旁观者，而是世界中的一个真实实体。玩家角色需要：

- 有可创建、可编辑的人物档案。
- 能在地图中移动、进入建筑、点击物品和实体。
- 能与 NPC 对话，并影响 NPC 记忆和关系。
- 能与动物互动，例如抚摸、喂食、靠近、惊吓。
- 玩家行为被世界记录为事件，被相关 NPC 感知和记住。

---

## 2. 玩家实体模型

```json
{
  "id": "player_001",
  "user_id": "user_001",
  "entity_type": "player",
  "name": "玩家",
  "appearance": {
    "hair": "black",
    "clothes": "casual",
    "sprite_sheet": "player_default.png"
  },
  "personality": ["友好", "好奇"],
  "background": "刚来到小镇的新居民。",
  "scene_id": "scene_town_outdoor",
  "position": { "x": 10, "y": 12 },
  "inventory": []
}
```

---

## 3. 交互半径

玩家只能与一定范围内的实体交互。

```json
{
  "player_id": "player_001",
  "interaction_radius": 2,
  "nearby_entities": ["npc_xiaofang", "animal_dog_doudou"],
  "nearby_objects": ["obj_cafe_table"]
}
```

交互判定由后端完成，前端只负责展示可交互提示。

---

## 4. 玩家输入类型

| 输入 | 后端处理 |
|------|----------|
| 键盘移动 / 点击地图 | 请求移动，后端路径与碰撞校验 |
| 点击 NPC | 检查距离，打开对话 |
| 点击动物 | 检查距离，触发动物反应工具 |
| 点击物品 | 检查权限和交互类型 |
| 输入文本 | 进入用户文本处理模块 |

---

## 5. API 设计

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/players` | 创建玩家角色 |
| `GET` | `/api/players/me` | 获取当前玩家 |
| `PATCH` | `/api/players/me/profile` | 修改玩家档案 |
| `POST` | `/api/players/me/move` | 请求移动 |
| `POST` | `/api/players/me/interact` | 请求交互 |
| `POST` | `/api/players/me/talk` | 向 NPC 输入文本 |

### 5.1 移动请求

```json
{
  "scene_id": "scene_town_outdoor",
  "target": { "x": 14, "y": 18 },
  "input_type": "click"
}
```

### 5.2 交互请求

```json
{
  "target_type": "animal",
  "target_id": "animal_dog_doudou",
  "interaction_type": "pet"
}
```

## 7. 玩家与 NPC 对话流程

```text
玩家点击 NPC
  ↓
后端检查交互半径和可见性
  ↓
前端打开对话框
  ↓
玩家输入文本
  ↓
用户文本处理模块：query 改写、意图识别、上下文召回
  ↓
NPC 生成结构化回复：文本 + 情绪 + 动作 + 记忆写入
  ↓
前端显示对话和动作
  ↓
双方写入记忆，更新关系
```

---

## 8. 与动物交互流程

```text
玩家点击狗/猫
  ↓
后端检查动物当前情绪、关系、距离
  ↓
动物 Agent 决策：享受、躲开、叫、靠近、攻击等
  ↓
生成世界事件
  ↓
写入玩家和动物相关记忆
```

示例结果：

```json
{
  "animal_id": "animal_cat_mimi",
  "reaction": "escape",
  "emotion": "scared",
  "description": "咪咪被突然靠近吓到，迅速跑到树后。",
  "relationship_delta": {
    "fear": 5,
    "affection": -2
  }
}
```

---

## 9. 验收标准

1. 用户能创建玩家角色并进入世界。
2. 玩家能移动、进入建筑、触发物品交互。
3. 玩家点击 NPC 能打开对话并输入文本。
4. 玩家点击动物能触发不同反应。
5. 玩家行为能写入 NPC/动物记忆，并影响后续关系。
