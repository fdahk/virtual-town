1.世界与地图：40×30 室外大地图 + 3 个 16×12 室内场景；咖啡店/学校/杂货店/花店/公园/河边长椅/6 处住宅；河流有 hazard+护栏，桥为安全通道；所有 portal 自动切换场景。

2.Agents：6 个 NPC（小芳/小明/小王/林娜/陈伯/阿言）+ 4 动物（豆豆/黑黑/咪咪/小白）+ 默认玩家，每个 NPC 都有完整日程模板。

3.仿真循环：SimulationEngine 驱动 world tick + AI tick 解耦，状态机 IDLE → THINKING → PLANNING_PATH → MOVING → INTERACTING；异步队列接玩家输入；增量通过事件总线广播。

4.规则版 AI：decide_human_action 根据当前游戏时间选日程 → A* 生成路径；decide_animal_action 按性格反应玩家（亲人靠近、胆小躲开、警觉观望、疲惫睡觉）。

5.LLM + 规则兜底：LLMClient OpenAI 兼容，JSON 输出 + Pydantic 校验；generate_npc_reply 未配置 API key 时自动走规则兜底，仿真永不崩溃。

6.记忆系统：写入 Postgres，三因素评分（recency 0.5 / importance 3.0 / relevance 2.0），有 embedding 用 cosine，无 embedding 退化为中英关键字相关性；种子中预置「小芳记得小王喜欢美式咖啡」这条演示记忆。

7.玩家交互：创建角色 → 地图点击/WASD 移动 → 走近 NPC 对话（调 LLM + 引用记忆）→ 走近动物抚摸/喂食/呼唤/惊吓（带关系更新）→ 走进河无护栏处触发 DROWNING。

8。端 UI：Phaser 用纯色矩形绘制 tile/building/object/sprite（MVP 免外部资源），React 负责所有面板；WebSocket 自动重连；调试层可开关碰撞/危险/出入口。

9.工程化：Docker Compose、Alembic 迁移、scripts/dev.sh 一键启动、openapi-typescript 可从 OpenAPI 生成前端类型、统一错误模型（code/message/retryable/details）、结构化日志。
